# LixLab · distribución

Sitio y archivos que consume el **LixLab Client**.

- `distribution.json` — manifiesto de perfiles y mods que lee el launcher
- `index.html` / `terminos.html` — landing y términos (GitHub Pages)
- **Releases** — instaladores del launcher y los mods de cada modpack

Se sirve por GitHub Pages en <https://bvnjx.github.io/lixlab-dist/>.
